## 发布与更新

- GitHub Pages 发布源：`gh-pages` 分支根目录。
- `main` 分支的 `dist/` 保留网页构建产物；只更新 `main` 不会自动更新网站。
- 更新网页后，将 `dist/` 内容同步到 `gh-pages`；GitHub Pages 构建完成后生效。
- 本机 Python/MySQL 完整 Demo 独立保留，后台管理和数据库写入未发布到此网站。
